# Spotify LRC Maker v1.2.0

## Highlights

- Timestamps now stay attached to matching lyric lines when lyrics are edited or when moving between the lyric editor and timestamp screen.
- Added chronological Undo and Redo for lyric edits, stamps, timing corrections, bulk shifts, clears, and lyric imports.
- Added capture offset and bulk timestamp shifting for faster timing correction.
- Added Quality Check before saving to flag incomplete, duplicate, out-of-order, empty, and out-of-duration timestamps.
- Added atomic UTF-8 saves, user-facing file errors, unsaved-change confirmation, automatic draft recovery, and startup recovery prompts.
- Added Spotify track lock to prevent timestamping a draft against a different track by accident.
- Added feedback for Spotify playback commands and disables unavailable media controls.
- Added recent files, remembered file-dialog folders, and drag-and-drop support for `.lrc` and `.txt` files.
- Added optional LRCLIB search. Results are shown in a picker and are imported only after explicit confirmation.

## Notes

- Manual, offline lyric editing and timestamping remain fully supported. LRCLIB is contacted only when **Import from LRCLIB** is selected.
- Unstamped lines are omitted from the exported LRC after confirmation.
- The timestamp editor retains its compact v1.1-style layout while using the safer v1.2.0 editing and save behavior.
