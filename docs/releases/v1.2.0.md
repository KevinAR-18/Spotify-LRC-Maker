# Spotify LRC Maker v1.2.0

## Highlights

- Preserves timestamps on matching lyric lines when editing lyrics or switching between the lyric editor and timestamp screen.
- Adds chronological Undo and Redo for lyric edits, timestamping, timing corrections, bulk shifts, clears, and lyric imports.
- Adds a configurable capture offset and bulk timestamp shifting for faster timing correction.
- Adds Quality Check before saving to identify incomplete, duplicate, out-of-order, empty, and out-of-duration timestamps.
- Adds safer file handling with atomic UTF-8 saves, clear file error messages, unsaved-change confirmation, automatic draft recovery, and recovery prompts at startup.
- Adds Spotify track locking to prevent a lyric draft from being timestamped against the wrong track.
- Adds feedback for Spotify playback commands and disables unavailable media controls.
- Adds recent files, remembered file-dialog locations, and drag-and-drop support for `.lrc` and `.txt` files.
- Adds optional LRCLIB lyric search with a result picker and explicit import confirmation.

## Notes

- Manual lyric editing and timestamping remain fully available offline.
- LRCLIB is contacted only when **Import from LRCLIB** is selected.
- Unstamped lyric lines are omitted from exported LRC files after confirmation.
- The timestamp editor retains its compact v1.1-style layout while gaining the safer v1.2.0 editing and saving workflow.
